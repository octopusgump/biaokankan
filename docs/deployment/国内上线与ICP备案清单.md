# 标看看｜国内上线与 ICP 备案清单

这份清单面向第一次在中国大陆上线网站的人。页面和部署结构已经准备好，但备案必须使用真实的公司、域名和服务器资料，代码不能代替备案审核。

## 一、先准备 4 样东西

1. **网站主办单位**：营业执照上的公司全称，主体、域名实名认证和备案申请尽量保持一致。
2. **域名**：建议使用简短的 `.cn` 或 `.com`，例如“品牌拼音 + 产品含义”；在国内注册商完成企业实名认证。
3. **中国大陆服务器**：选择阿里云、腾讯云、华为云等中国大陆地域的云服务器或静态网站服务。服务器接入商负责提交备案接入信息。
4. **网站负责人资料**：按接入商备案系统要求准备证件、手机号、邮箱和真实性核验材料。

已经确认的产品域名：

```text
biaokankan.com       首发主域名
biaokankan.cn        保护性备用域名
```

两个域名已于 2026 年 8 月 20 日在阿里云购买。首版统一使用 `biaokankan.com`，产品介绍和工作台放在同一网站。`biaokankan.cn` 作为保护性备用域名，首次备案期间暂不解析；后续将它纳入备案并配置 HTTPS 后，再跳转到 `https://biaokankan.com`，不建设第二套网站。

## 二、备案前只改一个配置文件

打开 `app/site-config.ts`，填写真实资料：

```ts
operatorName: "营业执照上的公司全称",
contactEmail: "对外服务邮箱",
contactPhone: "对外服务电话",
icpNumber: "豫ICP备XXXXXXXX号-1",
policeRecordNumber: "豫公网安备 XXXXXXXXXXXXXX号",
policeRecordUrl: "公安备案系统提供的查询链接",
```

注意：

- ICP 号没有审核通过前保持为空，不要编造或借用其他主体的备案号。
- 审核通过后，首页底部会显示 ICP 号并链接到工信部备案系统。
- 公安备案完成后再填写公安备案号和查询链接。
- 网站名称、主办单位、服务内容要与备案申请中的描述一致。

建议备案时的网站服务内容描述：

> 面向工程监理企业的信息工具，整理公开招标公告中的项目名称、截止时间、招标人、代理机构等信息，提供检索和提醒；用户以原公告和招标文件为最终依据。

## 三、构建并部署到大陆服务器

### 方案 A：上传静态文件（最容易维护）

在项目目录执行：

```bash
pnpm run build:china
```

把生成的 `china-dist` 目录完整上传到服务器网站根目录，使用 Nginx 托管。示例配置已经放在 `deploy/china/nginx.conf`。

### 方案 B：Docker 部署

```bash
docker build -f Dockerfile.china -t biaokankan .
docker run -d --name biaokankan -p 80:80 biaokankan
```

正式环境还应在云厂商控制台配置 HTTPS 证书，并把 80 端口跳转到 443。

## 四、上线顺序

1. 购买并实名认证域名。
2. 购买中国大陆地域服务器。
3. 在服务器接入商的备案系统提交 ICP 备案。
4. 根据接入商要求放置备案核验页或保持网站关闭状态。
5. 备案通过后解析域名、配置 HTTPS，并填写真实备案号。
6. 网站开通后按所在地要求办理公安联网备案。
7. 检查首页底部的主办单位、ICP 号、公安备案号与审核资料一致。

## 五、上线前检查

- 首页能直接看懂网站提供什么服务，不能只有登录框或空白页。
- 不出现虚假的政府背书、资质、中标承诺或“100% 不漏项目”等表述。
- 原公告链接清楚，显著提示“以原公告和招标文件为准”。
- 隐私说明和服务条款可从首页底部访问。
- 主办单位名称、域名主体、备案主体、服务器接入信息一致。
- ICP 备案号位于首页底部并链接 `https://beian.miit.gov.cn/`。
- 开通账号、日志、企业微信通讯录等能力前，补全正式隐私政策与个人信息处理规则。
- 如果以后提供付费信息服务，先让接入商或所在地通信管理局确认是否还需经营性互联网信息服务许可；不要仅凭页面文案自行判断。
