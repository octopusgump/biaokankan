## 2. 最终决策

### 2.1 使用已购买的独立中国大陆 ECS

不使用现有美国（弗吉尼亚）服务器承载标看看的国内正式站。原因是：

1. 美国地域的云服务器不能作为阿里云 ICP 备案的中国大陆接入资源。
2. 现有服务器已运行 OpenClaw 及其他业务，2 核 2 GiB 内存和 40 GiB 磁盘的余量不适合再承载国内正式站。
3. 新站独立后，备案、域名、证书、日志、备份和故障影响范围都更清楚。

现有美国服务器保持不变，继续承载当前 OpenClaw 和其他已有业务。

### 2.2 命令助手不用来“区分业务”

阿里云命令助手只是向某台服务器执行命令的维护工具，不会：

- 把一台服务器变成多台独立服务器；
- 改变服务器的地域；
- 让美国服务器变成可用于 ICP 备案的中国大陆接入资源；
- 隔离内存、磁盘、网络、进程和故障。

命令助手可以用于安装 Nginx、部署网站和查看运行状态，但业务隔离由独立 ECS、目录、服务和网络规则共同完成。

### 2.3 域名只有一个入口

- 唯一首发入口：`https://biaokankan.com`；
- `www.biaokankan.com` 使用 301 跳转到 `https://biaokankan.com`；
- `biaokankan.cn` 在未纳入 ICP 备案前不解析、不跳转、不对外提供网站；
- `biaokankan.cn` 后续纳入备案并配置 HTTPS 后，再将所有访问 301 跳转到 `https://biaokankan.com`。

## 3. 目标架构

```text
国内用户
   │
   ▼
biaokankan.com / www.biaokankan.com
   │  阿里云 DNS，备案通过后才解析
   ▼
阿里云中国大陆 ECS
   │
   ├─ Nginx：HTTPS、域名跳转、静态文件
   ├─ 标看看前端：china-dist
   └─ 数据快照：public/data/radar.json

现有美国服务器
   └─ OpenClaw 与其他现有业务，不承载标看看国内正式站
```

首版是静态站点加 JSON 数据快照，不需要在生产环境运行数据库，也不需要为它购买大规格服务器。

## 5. 从现在到上线的执行顺序

### 阶段 A：完成域名实名信息同步

1. 在阿里云域名详情中确认 `biaokankan.com` 的域名持有者是“正博星元工程管理咨询有限公司”。
2. 不要用个人姓名或其他公司作为主域名持有者。
3. 确认企业实名认证已通过，域名详情中证件类型和证件号码正确。
4. 实名信息刚通过或刚变更时，等待约 3 天再提交备案，让域名信息完成同步。
5. 等待期间不将 `biaokankan.com` 解析到中国大陆服务器，也不用 IP 对外宣传。

完成标准：域名状态正常，持有者、备案主体和营业执照主体一致。

### 阶段 B：初始化大陆服务器（已完成）

1. 使用第 4 节记录的独立大陆 ECS。
2. 使用 SSH 密钥登录，不以简单密码作为长期登录方式。
3. 更新系统安全补丁，并准备 Nginx、Node.js 22 和 pnpm。
4. 防火墙只开放：
   - TCP 80：公网访问，上线后用于跳转 HTTPS；
   - TCP 443：公网 HTTPS；
   - TCP 22：只允许管理员的固定 IP；如无固定 IP，需要时临时开放，用完关闭。
5. 不公开数据库、Node 开发端口、Docker 守护进程端口或其他调试端口。
6. 开启阿里云快照，首次部署完成后手动创建一份基线快照。

完成结果：服务器位于中国大陆，基础配置已通过健康检查；80、443 用于网站访问，22 仅用于受限管理。阿里云安全组与 Ubuntu UFW 必须保持同一开放策略。

### 阶段 C：准备首版网站

1. 项目配置中的主域名统一设为 `biaokankan.com`。
2. 执行 `pnpm run build:china`，生成 `china-dist`。
3. 使用 Nginx 托管静态文件。推荐目录约定：

   ```text
   /var/www/biaokankan/current/       当前线上版本
   /var/www/biaokankan/releases/      历史发布版本
   /var/www/biaokankan/shared/data/   抓取数据快照
   /var/log/nginx/                    Nginx 访问与错误日志
   ```

4. 页面底部在备案通过前保持 ICP 号为空，不填写示例号码。
5. 页面明确显示：
   - 标看看；
   - 帮监理企业更早发现值得跟进的标讯；
   - 信息来自公开招标公告；
   - 以原公告和招标文件为准；
   - 备案主体全称、隐私说明和服务条款入口。
6. 首版不开放对外注册、不收费、不展示支付功能、不宣称中标保证。

首次备案审核期间，按阿里云备案页面的要求保持网站关闭或仅放置指定的备案核验页，不提前公开正式业务。

完成标准：大陆服务器内已准备好真实的标看看页面，但在备案通过前不公开。

### 阶段 D：提交阿里云 ICP 备案

在阿里云 ICP 备案系统中按以下口径填写：

| 备案字段 | 填写口径 |
| --- | --- |
| 备案类型 | 企业首次备案；如主体已有备案，按系统判断选择新增网站 |
| 主办单位 | 正博星元工程管理咨询有限公司 |
| 网站名称 | 以已经提交的备案订单和最终审核结果为准 |
| 域名 | `biaokankan.com` |
| 服务内容 | 面向工程监理企业的信息工具，整理公开招标公告中的项目名称、截止时间、招标人、代理机构等信息，提供检索和提醒；用户以原公告和招标文件为最终依据 |
| 当前经营性质 | 当前仅企业内部使用，不收费，不向外部用户开放注册 |
| 服务器 | 已提交备案所绑定的华北 2（北京）ECS 备案服务资源 |

注意事项：

1. 备案已经提交；审核期间不要为了统一文案而修改网站名称、主体、负责人或服务内容。审核通过后，首页展示名称以最终获批信息为准。
2. 河南企业备案按当地规则准备最新营业执照，主体负责人按要求由法定代表人办理。
3. 准备备案负责人证件、手机号、邮箱、应急联系方式和网站备案承诺书。
4. 所有信息以营业执照、域名实名认证和备案系统中的真实信息为准，不在代码或文档中保存证件照片、验证码和密码。
5. 完成阿里云初审、负责人真实性核验和管局审核；期间注意接听核验电话和查收短信。

完成标准：管局审核通过，获得真实的 ICP 备案号。

### 阶段 E：备案通过后正式上线

1. 在阿里云 DNS 中为 `biaokankan.com` 添加指向大陆服务器公网 IP 的 A 记录。
2. 为 `www.biaokankan.com` 添加指向主域名的 CNAME，或指向同一公网 IP，并在 Nginx 中跳转至无 `www` 主域名。
3. 为 `biaokankan.com` 和 `www.biaokankan.com` 申请并安装 HTTPS 证书。
4. 强制将 HTTP 301 跳转至 HTTPS，并将 `www` 301 跳转至无 `www` 主域名。
5. 在 `app/site-config.ts` 中填写审核通过的真实 ICP 备案号，重新构建和发布。
6. 确认首页底部的 ICP 备案号链接至 `https://beian.miit.gov.cn/`。
7. 在电脑、手机和不同网络下验证首页、项目列表、原公告链接、HTTPS 和数据更新时间。
8. 网站开通后，按公安机关的页面指引和时限办理公安联网备案。
9. 公安备案通过后，把公安备案号和查询链接填入项目配置，再次发布。

完成标准：`https://biaokankan.com` 可稳定访问，浏览器无证书错误，页面底部的备案信息真实且可查询。

### 阶段 F：稳定运行和数据更新

1. 保留当前“每日两次抓取”的节奏。
2. 首选将抓取任务运行在大陆服务器上，使用定时任务调用项目现有爬虫，并通过 `TENDER_SNAPSHOT_PATH` 将结果写入 Nginx 对外托管的 `data/radar.json`。
3. 抓取失败时保留上一次成功快照，不用空文件覆盖正常数据。
4. 每日查看最近一次更新时间和异常来源；每周查看磁盘、内存和 Nginx 错误日志。
5. 每周保留一份服务器快照，重大发布前另外创建手动快照。
6. 至少保留上一个可回退的网站发布版本。

## 6. `biaokankan.cn` 的处理方式

首次上线不让 `.cn` 域名参与，具体是：

1. 等待注册局审核完成并确认企业实名信息正确。
2. 保持域名不解析，不指向美国服务器或大陆服务器。
3. 开启自动续费，作为保护性域名持有。
4. `biaokankan.com` 稳定运行后，在阿里云备案系统中按当时规则为 `.cn` 办理新增网站或域名相关手续。
5. 只有 `.cn` 已纳入备案且 HTTPS 证书生效后，才配置到 `.com` 的 301 跳转。

## 7. 首版不做的事

- 不迁移、重置或删除现有美国服务器；
- 不用命令助手代替服务器隔离；
- 不在首版引入用户注册、支付、会员套餐或客户数据库；
- 不在备案通过前把主域名解析到中国大陆服务器并公开网站；
- 不填写虚假的 ICP 号或公安备案号；
- 不为 `.cn` 建设第二套网站；
- 不在本阶段做品牌视觉设计。

## 9. 将来收费和开放外部注册前的升级门槛

未来启用收费或外部客户注册时，不直接在当前首版上打开开关。先完成：

1. 根据实际收费和信息服务模式，向阿里云备案顾问或河南省通信管理局确认是否需要经营性互联网信息服务许可；
2. 补全正式用户协议、隐私政策、个人信息处理规则、账号注销和客服流程；
3. 将账号、权限、业务数据和备份迁移到适合的 ECS、RDS 和对象存储架构；
4. 接入支付前完成合同、发票、退费、对账和客服方案；
5. 进行账号安全、越权、日志留存、备份恢复和容量压力测试。

## 10. 当前的下一步

严格按以下顺序执行：

1. 保持备案负责人手机号畅通，及时接听阿里云或管局核验电话。
2. 如收到工信部短信核验通知，按页面规定的期限完成核验。
3. 审核期间不修改已提交资料，不将 `biaokankan.com` 解析到大陆 ECS，也不用公网 IP 对外开放正式站。
4. 可以继续在受限环境中准备 Nginx、静态构建包和上线检查清单。
5. 管局审核通过后，再依次完成 DNS、HTTPS、HTTP/`www` 跳转、真实备案号展示和网站发布。
6. 网站正式开通后办理公安联网备案。
7. 网站稳定后，再决定 `biaokankan.cn` 的新增备案和跳转时间。
