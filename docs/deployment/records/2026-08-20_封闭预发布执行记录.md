## 4. 访问方法

管理员先建立本机 SSH 隧道：

```bash
ssh -L 18080:127.0.0.1:18080 deploy@ECS公网IP
```

保持该 SSH 连接打开，然后在本机访问：

```text
http://127.0.0.1:18080/
http://127.0.0.1:18080/radar
http://127.0.0.1:18080/radar/admin
```

不要把 ECS 公网 IP、域名或 `18080` 端口作为网站入口对外发布。

## 6. 停止和重新启动

停止前先读取并确认 PID 对应的是本预览脚本，再发送普通终止信号；不要使用模糊进程名批量终止。

重新启动时仍必须绑定 `127.0.0.1`，不得改为 `0.0.0.0`：

```bash
nohup setsid /usr/bin/python3 \
  /home/deploy/biaokankan-preview/preview_server.py \
  --directory /home/deploy/biaokankan-preview/current \
  --port 18080 \
  > /home/deploy/biaokankan-preview/logs/preview.log 2>&1 < /dev/null &
```

当前 `deploy` 账号没有免密 `sudo`，且 systemd user linger 未开启。因此本次没有修改系统服务；ECS 重启后需要人工重新启动封闭预览。

## 7. 后续发布和回滚
