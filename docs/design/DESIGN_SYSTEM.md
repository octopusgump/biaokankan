# 标看看黑蓝工作台设计系统

| 项目 | 内容 |
|---|---|
| 状态 | 正式规范 1.0 |
| 生效日期 | 2026-08-21 |
| 适用范围 | `/`、`/radar/`、`/radar/project/`、`/radar/admin/` 及后续新增页面 |
| 规范目标 | 全站只使用一套黑蓝工作台视觉语言，不再保留独立的绿色 Landing Page 主题 |

本文档是标看看 UI 设计与前端实现的唯一视觉规范。PRD 决定页面做什么，本文档决定页面如何呈现。两者冲突时，业务规则以 PRD 为准，视觉规则以本文档为准。

## 1. 设计定位

标看看是面向监理企业投标人员和管理人员的 B2B 数据工具。界面首先服务于快速阅读、风险识别、原公告核验和高频操作，不追求娱乐化、实验性或过度营销。

### 1.1 Design Read

这是一个面向专业用户的严肃 B2B 数据产品。视觉语言应克制、可信、信息优先，沿用现有黑色工作台框架、系统蓝强调色、浅灰页面背景和白色数据表面。

### 1.2 设计参数

| 参数 | 数值 | 含义 |
|---|---:|---|
| `DESIGN_VARIANCE` | 3 | 布局稳定、对齐明确，不使用实验性构图 |
| `MOTION_INTENSITY` | 2 | 只保留反馈与状态变化所需的轻动效 |
| `VISUAL_DENSITY` | 7 | 保持较高信息密度，但不牺牲可读性和触控尺寸 |

### 1.3 核心原则

1. **一个系统**：首页、雷达、详情和后台使用同一套颜色、字体、圆角、控件和导航。
2. **信息优先**：截止时间、项目名称、风险状态和原公告入口永远比装饰更重要。
3. **单一强调色**：系统蓝是唯一品牌与操作强调色。绿色、黄色、红色和紫色仅表达真实状态。
4. **边框优先**：主要依靠留白和 1px 边框组织层级，不用大面积阴影堆叠卡片。
5. **稳定优先**：不引入不必要的动画、渐变、发光、视差或滚动劫持。
6. **真实优先**：页面示意必须来自真实产品截图或真实组件，不制作假数据仪表盘。
7. **可核验**：任何数据状态都要有文字说明，不能只靠颜色或图标表达。

## 2. 技术与治理边界

### 2.1 当前技术选择

- 框架：React 19 与 Next.js 兼容路由层。
- 样式：Tailwind CSS v4 加项目自有原生 CSS。
- 组件：继续维护项目自有组件，不在当前阶段引入 Fluent、Carbon、Material 或其他整套 UI 库。
- 图标：当前已有符号可继续使用。需要引入图标库时，全站只选一个图标家族，优先 `@phosphor-icons/react`，安装后再使用。

这一选择以降低迁移成本为前提。后续如果页面规模或团队规模显著扩大，应单独评估组件库迁移，不得在同一版本混用两套设计系统。

### 2.2 规范治理

- 新增颜色、字号、圆角、层级或动效前，先更新本文档和全局 Token。
- 组件内禁止新增无语义的硬编码颜色。
- 同一意图的按钮在全站使用同一文案和样式。
- 新页面不得创建页面私有主题。
- 首页原有 `--public-*` 绿色主题变量应在改版时删除，不得继续扩展。
- 现有实现尚未迁移完成前，以本文档作为目标状态，以 `app/globals.css` 作为现状参考。

## 3. 颜色系统

### 3.1 颜色使用规则

- 页面只使用冷中性灰、近黑色和系统蓝作为基础视觉。
- 不使用暖米色、深绿色或独立营销色块。
- 不使用渐变文字、霓虹发光或蓝紫光晕。
- 近黑色代替纯黑色，减少视觉生硬感。
- 白色只用于内容表面、卡片、表格和输入控件。
- 状态色必须同时配文字，不得单独使用彩色圆点传达信息。

### 3.2 语义颜色 Token

```css
:root {

  --color-accent-hover: #0071e3;

  --color-focus: #0071e3;

  /* 文字 */
  --color-text-primary: #1d1d1f;
  --color-text-secondary: #333333;
  --color-text-muted: #6e6e73;
  --color-text-subtle: #86868b;
  --color-text-inverse: #ffffff;

  /* 表面 */
  --color-bg-page: #f5f5f7;
  --color-bg-surface: #ffffff;
  --color-bg-subtle: #fafafc;
  --color-bg-inverse: #1d1d1f;
  --color-bg-inverse-soft: #272729;

  /* 边界 */
  --color-border: #e0e0e0;
  --color-divider: #f0f0f0;

  /* 状态 */
  --color-success: #248a3d;
  --color-success-soft: #edf8ef;
  --color-warning: #a05a00;
  --color-warning-soft: #fff5e6;
  --color-danger: #c9342f;
  --color-danger-soft: #fff0ef;
  --color-pending: #76529b;
  --color-pending-soft: #f5effa;
}
```

### 3.3 状态颜色含义

| 状态 | 颜色 | 适用内容 | 禁止用法 |
|---|---|---|---|
| 蓝色 | `accent` | 链接、主按钮、选中态、焦点 | 不表示成功或正常 |
| 绿色 | `success` | 扫描成功、链接可访问、完成 | 不用于品牌和装饰 |
| 黄色 | `warning` | 临近截止、数据陈旧、部分失败 | 不用于普通提示 |
| 红色 | `danger` | 剩余 1 天、失败、删除、高风险 | 不用于普通强调 |
| 紫色 | `pending` | 待核验、信息不确定 | 不用于品牌和主操作 |

## 4. 字体与排版

### 4.1 字体家族

正文和控件使用系统无衬线字体，不加载外部字体，不使用衬线字体。

```css
--font-body: system-ui, -apple-system, BlinkMacSystemFont,
  "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif;

--font-display: "SF Pro Display", system-ui, -apple-system,
  "PingFang SC", "Microsoft YaHei", sans-serif;

--font-mono: ui-monospace, "SFMono-Regular", Consolas, monospace;
```

- `font-display` 仅用于页面主标题、详情标题和关键数字。
- `font-mono` 仅用于日志、记录编号、时间戳或机器字段，不用于所有数字。
- 普通数据数字使用 `font-variant-numeric: tabular-nums` 保持列对齐。

### 4.2 字号层级

| 角色 | 桌面 | 手机 | 字重 | 行高 | 使用位置 |
|---|---:|---:|---:|---:|---|
| Display | 48px | 34px | 600 | 1.07 | 首页和一级工作台主标题 |
| Page title | 40px | 28px | 600 | 1.10 | 详情页长标题 |
| Section title | 28px | 24px | 600 | 1.20 | 主要页面分区 |
| Component title | 21px | 18px | 600 | 1.30 | 卡片、面板、后台区块 |
| Body large | 17px | 17px | 400 | 1.47 | 页面说明、摘要正文 |
| Body | 14px | 14px | 400 | 1.50 | 控件、表格主信息 |
| Label | 12px | 12px | 500 或 600 | 1.45 | 表头、字段标签、辅助标题 |
| Micro | 10px | 10px | 400 或 600 | 记录编号、次要时间 |

规则：

- 全站只使用 400、500、600 三档主要字重。
- 不使用 650、700、800 制造品牌感。
- 页面主标题最多两行，长项目名称允许详情页在两到三行内自然换行。
- 正文段落推荐最大宽度 65 个西文字符，中文说明建议不超过 32 个汉字一行。
- 标题使用轻微负字距，正文不小于 `-0.01em`。
- 页面内不使用斜体作为装饰强调。

## 5. 间距与布局

### 5.1 间距 Token

所有间距基于 4px 网格。

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 20px;
--space-6: 24px;
--space-7: 28px;
--space-8: 32px;
--space-10: 40px;
--space-12: 48px;
--space-16: 64px;
--space-18: 72px;
--space-24: 96px;
```

- 同一组件内部优先使用 8px、12px、16px。
- 卡片内边距使用 20px、24px 或 32px。
- 页面区块之间使用 20px、24px、28px 或 48px。
- 不为单个页面发明 13px、15px、19px 等孤立间距。

### 5.2 页面容器

| 区域 | 规则 |
|---|---|
| 全局工作区 | 最大宽度 1440px，居中 |
| 桌面水平内边距 | `clamp(28px, 4.6vw, 72px)` |
| 桌面顶部内边距 | 48px |
| 桌面底部内边距 | 96px |
| 手机水平内边距 | 16px |
| 手机底部内边距 | 48px |
| 正文最大阅读宽度 | 720px 或 65ch |

### 5.3 布局原则

- 数据界面优先 CSS Grid，不使用复杂百分比 Flex 计算。
- 页面标题左对齐，不使用居中大标题。
- 同一页面只保留一个主视觉焦点。
- 卡片只在内容形成独立任务或状态时使用。
- 长列表优先表格或移动卡片，不把每个字段拆成独立装饰卡片。
- 文档页面不能出现整体横向滚动。只有明确的表格容器允许横向滚动。

## 6. 圆角、边框、阴影与层级

### 6.1 圆角比例

| Token | 数值 | 使用位置 |
|---|---:|---|
| `--radius-sm` | 8px | 品牌标识、紧凑按钮、微型容器 |
| `--radius-control` | 10px | 普通表单字段、抽屉内部控件 |
| `--radius-panel` | 14px | 汇总条、下拉菜单、分段控件 |
| `--radius-card` | 18px | 项目面板、详情卡片、后台卡片 |
| `--radius-pill` | 999px | 主按钮、搜索框、筛选器、标签 |

禁止新增 9px、11px、16px、20px 等相近但无语义的圆角。

### 6.2 形状规则

- 可点击主控件采用胶囊形，卡片和数据面板采用 18px 软圆角。
- 普通输入字段默认 10px。搜索、筛选和全局操作可以使用胶囊形。
- 状态标签使用胶囊形。
- 品牌标识使用 8px，不使用圆形 Logo 容器。

### 6.3 边框与阴影

- 默认卡片：1px `--color-border`，无阴影。
- 表格分隔：1px `--color-divider`。
- 下拉菜单、抽屉和对话框允许一层低对比阴影。
- 阴影必须带冷灰蓝色调，不使用纯黑大阴影。
- 不使用外发光。
- 模糊和半透明只允许用于临时浮层。必须提供不透明降级样式。

推荐浮层阴影：

```css
box-shadow:
  0 10px 30px rgba(30, 45, 65, .14),
  0 0 0 1px rgba(0, 0, 0, .06);
```

### 6.4 Z-index 比例

| 层级 | 数值 | 用途 |
|---|---:|---|
| Base | 0 | 普通内容 |
| Sticky content | 10 | 表头、页内粘性内容 |
| Popover | 30 | 下拉菜单、提示浮层 |
| Global header | 50 | 桌面顶栏 |
| Mobile header | 60 | 手机顶栏 |
| Navigation drawer | 80 | 手机导航抽屉 |
| Modal | 120 | 对话框和全局遮罩 |

不得使用未记录的任意大数值。

## 7. 响应式规则

### 7.1 固定断点

| 断点 | 语义 | 行为 |
|---|---|---|
| `1180px` | 紧凑桌面 | 筛选器允许换行，详情侧栏收窄 |
| `834px` | 手机与小平板 | 桌面导航切换抽屉，数据表切换项目卡片 |
| `640px` | 窄屏手机 | 筛选器单列，自定义 Select 切换原生 Select |
| `420px` | 小屏手机 | 主标题降为 28px，汇总控件收紧 |

首页不得另建 900px 等独立断点。全站使用同一断点集合。

### 7.2 表格适配

- 项目表格最小内容宽度可保持 1220px。
- 表格外层必须始终设置 `overflow-x: auto`，不能依赖单个媒体查询开启滚动。
- 当视口小于 834px 时，隐藏桌面表格，改为移动项目卡片。
- 页面本身不得因表格宽度产生横向滚动或裁切。
- 1280px、1180px 和 1024px 必须单独验收右侧列是否可访问。

### 7.3 移动卡片

- 卡片宽度为容器 100%。
- 内边距 20px，圆角 18px，卡片间距 12px。
- 截止时间放在最前，项目名称次之。
- 字段使用 72px 标签列加剩余内容列。
- 操作区固定在卡片底部，用 1px 分隔线与内容分开。
- 主次操作触控高度不低于 44px。

## 8. 全局外壳与导航

### 8.1 品牌标识

- 统一使用白色方形标记和“标看看”字标。
- 桌面标记为 24px，圆角 8px。
- 手机标记为 28px，抽屉内可使用 32px。
- 禁止首页使用绿色 Logo、绿色字标或第二套品牌标记。

### 8.2 桌面顶栏

- 高度 44px。
- 背景使用 `--color-bg-inverse`。
- 字标和品牌标记保持左侧，工作台导航保持右侧。
- 非激活导航使用中性灰，激活导航使用 `--color-accent-on-dark`。
- 导航必须保持单行。

### 8.3 手机顶栏与抽屉

- 手机顶栏高度 52px，粘附在视口顶部。
- 抽屉宽度 `min(84vw, 320px)`。
- 抽屉背景与桌面顶栏一致。
- 当前页面在抽屉中使用深灰表面加蓝色文字表示。
- 遮罩只负责聚焦，不使用强模糊和装饰动画。

## 9. 页面标题与内容头部

标准页面头部由以下内容组成：

1. 可选的日期、页面类别或面包屑。
2. 一个主标题。
3. 一段简短说明。
4. 可选的真实状态控件或页面主操作。

规则：

- 不使用 `01`、`02`、`03` 作为装饰性章节编号。
- 小标签必须提供真实分类信息，不能只是视觉装饰。
- 页面主说明最多 720px。
- 状态控件放在标题右侧，手机端可以隐藏或下移。
- 同一区域最多一个主操作。

## 10. 按钮与链接

### 10.1 按钮类型

| 类型 | 样式 | 使用场景 |
|---|---|---|
| Primary | 蓝底白字，胶囊形 | 页面唯一主操作 |
| Secondary | 白底蓝色边框和文字 | 与主操作并列的次要操作 |
| Ghost | 无底色，蓝色文字 | 筛选清除、返回、轻量操作 |
| Danger | 红色文字或红底白字 | 删除、停用等破坏性操作 |
| Disabled | 浅灰底、灰字 | 不可用操作，必须保留原因 |

### 10.2 尺寸

| 尺寸 | 高度 | 水平内边距 | 字号 |
|---|---:|---:|---:|
| Compact | 36px | 14px | 12px |
| Default | 44px | 18px 或 22px | 14px |
| Prominent | 48px | 20px 或 22px | 15px 或 17px |

### 10.3 交互状态

- Hover：主按钮切换为 `--color-accent-hover`。
- Active：缩放到 `0.985`，持续 80ms。
- Focus：2px 蓝色轮廓，外偏移 3px。
- Loading：按钮宽度不得跳变，保留原标签或同宽骨架。
- Disabled：必须有 `disabled` 属性，不只降低透明度。
- 按钮文字不得换行。主要 CTA 最多 6 个汉字。

### 10.4 文案一致性

- 进入雷达统一写“进入项目雷达”。
- 查看项目统一写“查看详情”。
- 打开来源统一写“打开原公告”。
- 清除筛选统一写“清除筛选”。
- 同一页面不得同时出现“进入雷达”和“开始使用”表达同一意图。

## 11. 表单、搜索与筛选

### 11.1 通用规则

- 标签位于字段上方。搜索框可使用可访问名称代替可见标签。
- Placeholder 只提供示例或输入提示，不能代替标签。
- 帮助文字位于字段下方。
- 错误信息紧邻字段下方，使用红色文字和明确原因。
- 标准控件高度 44px。
- 所有控件必须支持键盘导航和可见焦点。

### 11.2 搜索框

- 使用胶囊形，白色背景，1px 中性边框。
- 搜索图标放在左侧，图标不承担标签功能。
- 输入文字 14px，Placeholder 不低于可访问对比度。
- 清空按钮只有在存在输入时出现。

### 11.3 Select 与筛选器

- 桌面可以使用自定义 Listbox，但必须完整支持方向键、Home、End、Enter、Space、Escape 和 Tab。
- 640px 以下使用原生 Select。
- 选中项以蓝色浅底和勾选标记共同表达。
- Popover 圆角 14px，内边距 6px。
- 透明模糊不可用时切换为纯白背景。

## 12. 汇总条、标签与状态

### 12.1 汇总分段控件

- 三个汇总项使用同一个 14px 面板，不拆成三个悬浮卡片。
- 选中项使用白色表面和底部 2px 蓝线。
- 数字使用 30px 或手机 24px 到 26px，字重 600。
- 标题使用 12px 到 13px，说明使用 10px 到 11px。
- 状态颜色只用于相关说明，不给整个分段填充彩色背景。

### 12.2 状态标签

- 标签必须包含文字，例如“成功”“临近截止”“待核验”。
- 圆点只在表达实时健康状态时使用。
- 不在每一行、每个导航项或每个标签前放装饰圆点。
- 一个标签只表达一个状态。

## 13. 卡片、面板与详情页

### 13.1 标准面板

- 白色背景、1px 边框、18px 圆角、默认无阴影。
- 内边距根据密度使用 20px、24px 或 32px。
- 面板标题 21px，字重 600。
- 多个并列面板使用 20px 间距。

### 13.2 详情摘要区

详情页允许使用一块深灰反色摘要区。这是全站唯一允许的大面积反色内容区，作用是快速建立项目身份和时间优先级。

- 背景使用 `--color-bg-inverse-soft`。
- 标题使用白色，最大 40px。
- 标签使用透明背景和中性灰边框。
- 时间卡使用稍浅的深灰表面，圆角 18px。
- 蓝色只用于可点击内容和真实更新状态。
- 长项目名称必须自然换行，不能横向裁切。

### 13.3 字段网格

- 桌面两列，834px 以下单列。
- 字段格最小高度 92px，内边距 18px。
- 标签 12px，值 14px，字重 600。
- 只使用一组共享分隔线，不叠加阴影。
- 长依据文本允许跨整行展示。

## 14. 数据表格

### 14.1 信息优先级

项目表列顺序固定为：

1. 投标截止。
2. 项目名称与标段。
3. 总投资。
4. 招标人。
5. 招标代理机构。
6. 信息来源与原公告。

不得为了视觉平衡改变这一顺序。

### 14.2 表格视觉

- 表头使用 12px、600 字重、浅灰表面。
- 数据行使用白色背景和单条分隔线。
- Hover 只改变为极浅冷灰，不抬升卡片。
- 项目名称使用蓝色链接样式。
- 数值使用等宽数字特性并右对齐，文字字段左对齐。
- 同一行只显示业务需要的真实状态标记。

### 14.3 表格行为

- 表头和数据列必须保持对齐。
- 表格容器允许横向滚动，页面容器不允许。
- 键盘用户能到达项目链接和原公告按钮。
- 不使用截断隐藏关键时间和项目名称。可截断次要单位名称，但必须提供完整标题或详情入口。

## 15. Loading、空、异常与陈旧数据

### 15.1 Loading

- 使用与最终内容结构一致的骨架，不使用通用圆形 Spinner 作为主状态。
- 骨架不得改变最终布局尺寸。
- 动画只允许低对比度明暗变化，并尊重减少动态效果设置。

### 15.2 空状态

空状态需要说明三件事：

1. 当前发生了什么。
2. 为什么可能发生。
3. 用户可以做什么。

筛选无结果与真实扫描无项目必须使用不同文案。

### 15.3 错误状态

- 数据不可读取时明确说明不使用 Demo 数据替代。
- 表单错误靠近字段，运行错误放在对应来源或项目附近。
- Toast 只用于短暂反馈，不承载需要用户长期查看的错误。

### 15.4 陈旧数据

- 使用黄色软背景和明确的扫描时间。
- 文案必须说明当前显示上次成功数据。
- 不得继续显示绿色“扫描正常”。

## 16. 首页统一规范

首页的信息架构可以继续承担产品介绍，但视觉必须完全并入黑蓝工作台系统。

### 16.1 必须使用

- 与工作台相同的黑色顶栏、白色品牌标记和蓝色激活色。
- 与工作台相同的字体、背景、按钮、卡片、圆角和断点。
- 左对齐主标题，最大 48px，桌面最多两行。
- 一个主 CTA“进入项目雷达”，最多一个次 CTA“了解工作方式”。
- 真实项目雷达截图或真实组件截图作为主要产品视觉。
- 浅灰页面背景、白色内容表面和深灰页脚。

### 16.2 禁止保留

- 绿色 Logo、绿色按钮、绿色标题和绿色 Footer。
- `--public-*` 私有主题 Token。
- 暖米色产品边界区。
- 68px 超大营销标题。
- 三张完全相同的营销功能卡。
- 旋转的假仪表盘或由普通 Div 拼出的假产品截图。
- 页面中途切换成另一套暖色主题。

### 16.3 首页内容密度

- 首屏只包含可选类别、主标题、简短说明和 CTA。
- 中文首屏说明建议不超过 60 个汉字，最多四行。
- 产品证据放在首屏之后，使用真实数据、真实截图或简洁数据条。
- 多于五项的能力说明使用分组或折叠，不使用长串普通卡片。

## 17. 文案与视觉语气

### 17.1 文案原则

- 使用具体、功能性的中文。
- 不使用“颠覆”“赋能”“革命性”“无缝”等空泛词。
- 不使用虚构精确数字。
- 不使用破折号作为装饰或句式捷径。
- 元信息每行最多使用一个中点分隔符。
- 日期范围和编号使用普通连字符。
- 状态和风险文案优先说明事实，不制造紧张感。

### 17.2 标题原则

- 页面标题说明用户正在处理的对象。
- 分区标题直接说明内容，不使用“01”“02”或“探索更多”等装饰标签。
- 标题不使用随机斜体、衬线字体或渐变文字。
- 标题不依赖强制换行制造视觉效果。

## 18. 动效规范

### 18.1 动效 Token

```css
--motion-press: 80ms;
--motion-fast: 120ms;
--motion-base: 140ms;
--motion-soft: 160ms;
--ease-ui: cubic-bezier(.2, .8, .2, 1);
```

### 18.2 允许的动效

- 按钮按压缩放。
- Hover 和 Focus 的颜色、边框变化。
- 下拉菜单 120ms 的透明度和 2px 位移。
- 抽屉短距离滑入。
- 真实更新或危险截止提示最多播放两次注意动画。

### 18.3 禁止的动效

- 无限循环装饰动画。
- 页面滚动劫持、视差、磁吸按钮和鼠标跟随。
- 动画宽度、高度、top 或 left。
- 纯粹为了“更有科技感”而加入的粒子、光晕和闪烁。

所有动画只使用 `transform` 和 `opacity`，并在 `prefers-reduced-motion: reduce` 下缩短为近乎即时。

## 19. 可访问性

### 19.1 基本要求

- 普通文字与背景对比度至少 4.5:1。
- 大号文字至少 3:1。
- 触控目标建议 44px，任何主要操作不得低于 36px。
- 所有可交互元素支持键盘操作。
- Focus 不能被 `outline: none` 删除。
- 信息不能只通过颜色传达。
- 图标按钮必须有可访问名称。
- 表单字段必须有 Label 或等价的可访问名称。

### 19.2 系统偏好

- 支持 `prefers-reduced-motion`。
- 浮层支持 `prefers-reduced-transparency` 的纯色降级。
- 支持 `forced-colors: active`，选中态不能只靠背景色。
- 当前版本统一使用浅色工作台主题，不要求实现完整暗色模式。黑色顶栏和详情摘要区是浅色主题中的反色表面。

### 19.3 表格与列表

- 表头使用正确语义或等价 ARIA 关系。
- 行内操作具有明确名称，不能只写“查看”。
- 桌面表格切换为移动卡片后，信息顺序保持一致。

## 20. 禁止项

以下内容不得出现在新页面或改版页面中：

- 第二套页面私有主题。
- 绿色作为品牌主色或主 CTA。
- 组件内随意硬编码颜色。
- AI 紫色渐变、外发光和霓虹效果。
- 大面积玻璃拟态。
- 纯装饰状态圆点。
- 装饰性章节编号。
- 三张相同的营销功能卡。
- 假产品截图、假版本号和假运行状态。
- 无意义的超大标题。
- 按钮文案换行。
- Placeholder 代替 Label。
- 关键数据因容器裁切而不可访问。
- 页面整体出现横向滚动。

## 21. 实施顺序

为了控制成本，统一改版按以下顺序实施：

1. **Token 收敛**：在 `globals.css` 建立语义颜色、圆角和间距 Token，同时保留旧 Token 映射。
2. **首页换肤**：删除 `--public-*`，复用工作台外壳、品牌标记、蓝色按钮和浅灰背景。
3. **形状统一**：将零散的 9px、11px、16px、20px 圆角迁移到标准比例。
4. **表格修复**：让表格容器始终可横向滚动，验证 1280px 右侧列。
5. **装饰清理**：移除详情分区编号、非语义圆点和不必要阴影。
6. **状态验收**：检查 Loading、空、错误、陈旧数据和待核验状态。
7. **响应式验收**：覆盖 1440、1280、1180、1024、834、640、390px。

不得在一次样式提交中同时修改业务数据、路由、字段顺序或抓取逻辑。
