# PRD_002A｜GitHub Pages 临时加密试用

> 状态：已上线，待产品负责人使用真实临时密码验收｜2026-08-21

## 一、这是什么？

ICP 审核期间保留 `https://octopusgump.github.io/biaokankan/`。用户输入共享密码后，浏览器解密标讯并进入网站。

| | Pages 临时解锁 | 正式账号登录 |
|---|---|---|
| 识别对象 | 只确认知道共享密码 | 识别企业和个人 |
| 记忆方式 | 浏览器保存派生密钥 30 天 | 服务端登录会话 |
| 使用期限 | ECS 验收完成前 | ICP 后另行开发 |

**解锁不等于登录。** Pages 不知道访问者是谁，也没有退出、找回密码或个人权限。

## 二、项目边界

**本项目只做 GitHub Pages 静态内容加密。** 原爬虫、页面、数据结构和深层路由继续使用。

不建设 ECS、账号数据库、Cookie 会话、注册、权限、日志或企业数据隔离；不修改域名、DNS 和 ICP 配置。ICP 后内容归 [PRD_002B](./PRD_002B_ECS访问控制与企业账号.md)。

Pages 产物不含明文标讯。Public 仓库和 Git 历史里已经提交的明文快照需另做仓库私有化或数据迁移，本项目不处理。

## 三、解锁页长这样

```text
标看看 · 封闭试用

输入临时访问密码
解锁后，此浏览器会安全记住 30 天。

[访问密码____________]
[进入标看看]

新设备、无痕窗口、清除网站数据或密码版本更新后需要重新输入。
```

错误密码显示“密码不正确，请重新输入。”；密文不可用时显示“暂时无法读取加密数据”，不展示项目数量、名称或备用明文。

## 四、访问规则

| 情形 | 结果 |
|---|---|
| 首次访问 | 显示解锁页 |
| 密码正确 / 错误 | 解密并进入 / 清空输入并留在原页 |
| 30 天内再次访问 | 本地凭证有效时自动解锁 |
| 新设备、无痕、清除数据 | 重新输入密码 |
| `keyVersion` 改变或凭证过期 | 删除旧凭证，重新输入密码 |
| 密文缺失、损坏或解密失败 | 失败关闭，不显示备用数据 |

`/`、`/radar/`、`/radar/project/`、`/radar/admin/` 共用同一解锁状态，直接打开和刷新都不能绕过。

## 五、数据与安全规则

1. 密码只从 Secret `BIAOKANKAN_PREVIEW_PASSWORD` 读取，真实值不能进入源码、测试、Workflow、文档、日志或产物；
2. 测试只用独立模拟密码；
3. 明文 `public/data/radar.json` 只在 Actions runner 内短暂存在，Pages 只发布 `data/radar.enc.json`；
4. 使用 PBKDF2-HMAC-SHA256 600,000 次和 AES-256-GCM；
5. 密码版本不变时沿用随机盐和 `keyVersion`，每次发布仍生成新 IV；
6. 更换密码时同时更换盐和 `keyVersion`，旧凭证立即失效；
7. IndexedDB 只保存不可导出的 `CryptoKey`、`keyVersion`、`expiresAt`，有效期 2,592,000,000 毫秒；
8. Secret 缺失、加密失败或产物审计失败时停止发布，不能退回明文。

字母临时密码由产品负责人自行设置，本阶段不要求另外生成超高强度随机密码。静态密文仍可能被离线猜测，不能长期使用。

## 六、交付数量

```text
解锁页 1 个｜加密快照 1 个｜Secret 1 个｜本地凭证记录 1 条｜受保护入口 4 类
```

4 类入口共用一套密码和凭证，不能算成 4 套系统。

## 七、职责

| 负责人 | 要完成的事 |
|---|---|
| 产品负责人 | 设置并线下分发密码；更换密码时通知轮换版本 |
| 开发 | 维护加密、解锁、路由和测试 |
| GitHub Actions | 读取 Secret、加密、审计、发布 |

## 八、验收

1. 无痕窗口打开四类入口时都先显示解锁页；
2. 正确密码显示当前真实标讯，错误密码不能进入；
3. 普通浏览器重开可自动解锁，无痕或清除数据后重新输入；
4. 线上 `/data/radar.json` 返回 404，`/data/radar.enc.json` 只有密文；
5. 产物搜索不到真实密码和代表性项目名称；
6. Secret 缺失、为空或加密失败时 Workflow 失败且不部署；
7. `keyVersion` 改变后旧凭证失效；
8. 四类深层路由均可直接打开和刷新；
9. lint、Pages 构建、爬虫和现有页面测试全部通过。

操作命令见[《GitHub Pages 临时加密试用》](../deployment/GitHub%20Pages临时加密试用.md)。
