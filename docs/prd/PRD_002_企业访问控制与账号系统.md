# 标看看｜企业访问控制与账号系统 PRD

> 状态：ICP 前 Pages 临时加密代码已完成、待首次发布验收；ECS 访问控制代码已完成、待 ICP 通过后部署；独立账号系统待后续开发｜更新时间：2026-08-21

> 一句话：ICP 审核期间继续使用 GitHub Pages，但标讯内容加密且同一浏览器 30 天内只输入一次共享密码；ICP 通过后切换到 ECS 正式入口，再升级企业个人账号。

> **本 PRD 覆盖 PRD_001 中“GitHub Pages 公开试用”的访问规则。** ICP 审核期间允许保留 Pages 地址，但发布包不得包含明文标讯；ICP 通过并完成 ECS 验收后关闭 Pages 业务入口。

## 一、这是什么？

这是标看看从公开演示转为企业使用的访问门禁，分三个可以单独验收的阶段。

| | 谁能访问 | 怎么进入 | 什么时候结束 |
|---|---|---|---|
| **临时阶段：Pages 加密试用** | 知道临时共享密码的人员 | 首次输入密码；同一浏览器记住 30 天 | ICP 通过且 ECS 验收完成 |
| **正式入口阶段：ECS 访问控制** | 公司网络和已获准的企业 | 公司公网 IP 免密；其他网络输入企业专属用户名和密码 | 独立账号系统上线 |
| **长期阶段：企业账号** | 被邀请且账号有效的个人用户 | 每人使用自己的邮箱和密码登录 | 作为正式长期方案 |

**“本地记住密码”不等于服务端登录。** Pages 临时阶段只保护发布内容，无法识别具体用户；临时密码、企业凭证都不能迁移成正式用户密码。

## 二、项目边界

**临时阶段只做 GitHub Pages 静态内容加密。** 增加解锁页，将标讯快照加密后发布，并在同一浏览器保存 30 天解密凭证；不建设服务器、用户数据库、Cookie 会话、注册、找回密码、个人权限或访问日志。临时密码通过 GitHub Actions Secret 注入，不能写入代码、PRD、构建产物或仓库历史。

**正式入口阶段只做 ECS 服务器访问控制。** 不改业务页面，不建设用户数据库；公司公网 IP 免密，其他网络使用企业专属凭证。访问日志只能说明使用了哪个企业凭证，不能证明具体是哪位员工。

**长期阶段只做邀请制企业账号。** 包含企业、个人账号、登录、激活、重置密码、停用、角色和登录日志；不开放公众自主注册，不做微信登录、短信登录、单点登录、多因素认证、套餐、支付、合同或发票。

本期所有企业看到同一份标讯数据，不做企业专属数据、项目分派、收藏或跟进记录。以后增加企业业务数据时，必须按企业隔离，不能把本期“共用标讯”理解为“企业之间可以共用业务记录”。

大陆 ECS 可以在 ICP 审核期间完成开发和封闭验收，但 **ICP 通过前不得通过域名或公网 IP 向三家企业开放**。Pages 发布包只能包含解锁壳和密文，不能把普通前端密码框盖在明文 `radar.json` 上；直接访问密文文件也不能读出项目内容。

## 三、用户实际看到什么？

### 临时阶段：GitHub Pages

首次访问 `/radar/` 时显示：

```text
标看看封闭试用

请输入临时访问密码
[_______________________]

[进入标看看]
```

密码正确后进入原页面；同一浏览器 30 天内自动解锁。解锁凭证保存在 IndexedDB，不使用 GitHub 无法校验的普通 Cookie，也不保存密码原文。

### 正式入口阶段：ECS

公司网络直接进入原网站。其他网络由浏览器显示原生认证框：

```text
标看看封闭试用

用户名：[____________]
密码：  [____________]

[登录]
```

认证通过后直接进入用户原本访问的页面，不增加中间欢迎页。浏览器原生认证框的样式不做定制。

### 长期阶段：企业账号

未登录用户访问任何业务页面时进入 `/login`：

```text
登录标看看
使用企业分配的账号继续

企业邮箱
[name@company.com       ]

密码
[_______________________]

[登录]
忘记密码
```

系统把激活或重置链接发送到账号邮箱。受邀用户通过激活链接进入 `/activate`，设置密码后进入 `/radar/`。被停用、邀请失效或无权限时只显示明确原因，不展示标讯内容。

## 四、访问状态与规则

### 临时阶段：GitHub Pages

| 情形 | 结果 |
|---|---|
| 首次访问或本地凭证过期 | 显示解锁页 |
| 密码正确 | 解密标讯并进入；本地凭证有效 30 天 |
| 密码错误 | 保持在解锁页，不显示项目名称、数量或详情 |
| 同一浏览器再次访问 | 本地凭证有效时自动解锁 |
| 新设备、无痕窗口或清除网站数据 | 重新输入密码 |
| 直接访问数据文件 | 只能获得 AES-GCM 密文，不能获得明文 JSON |

构建使用 Web Crypto 兼容格式：PBKDF2-HMAC-SHA256、至少 600,000 次迭代，派生 AES-256-GCM 密钥。每次更换密码时生成新的随机盐并提升 `keyVersion`；密码不变期间复用该盐，让 30 天本地凭证可以继续解密后续更新。每次发布仍使用新的随机 IV。临时密码由产品负责人自行设置，并仅写入 GitHub Actions Secret，**Secret 的真实值不得出现在仓库中**。由字母组成的临时密码用于控制试用访问；产品负责人接受静态站点口令无法抵抗有目的离线猜测的边界，本阶段不要求另外生成超高强度随机密码。

Pages 工作流生成加密发布包后，必须检查产物中不存在明文 `radar.json`、项目名称或临时密码。保存到 IndexedDB 的是可恢复解密能力的本地凭证，因此共用电脑必须使用独立浏览器账号，不能把“记住 30 天”理解成退出登录。

### 正式入口阶段：ECS

| 情形 | 结果 |
|---|---|
| 公司已登记的公网 IPv4 / IPv6 | 不弹密码框，直接访问 |
| 公司公网 IP 变化 | 自动降级为密码访问，不扩大白名单 |
| 外部网络首次访问 | 返回认证框 |
| 企业凭证正确 | 可访问全部已授权页面和数据 |
| 凭证错误或已撤销 | 拒绝访问，不泄露页面和 `radar.json` |
| HTTP 访问 | 先跳转 HTTPS，再认证；密码不能通过 HTTP 发送 |
| 服务器 IP、旧域名或 GitHub Pages 地址 | 不得成为绕过认证的入口 |

每家试用企业使用独立凭证；不发一个三家共用的总密码。密码至少 12 位随机字符，只保存哈希，放在服务器受限文件中，不进入代码仓库、前端包或文档。某家退出试用时只撤销该家凭证。

连续认证失败需要限速并写入安全日志。所有页面、脚本、图片和 `/data/radar.json` 使用同一套规则，**只锁首页不算完成**。

### 长期阶段：企业账号

| 状态 | 用户看到什么 |
|---|---|
| 未登录 | 跳转登录页，登录后回到原访问地址 |
| 邀请未激活 | 只能设置密码，不能进入业务页面 |
| 账号有效 | 进入项目雷达 |
| 密码错误 | 提示“邮箱或密码不正确”，不暴露邮箱是否存在 |
| 连续失败 5 次 | 该账号暂停登录 15 分钟 |
| 会话超过 7 天或账号被停用 | 会话失效，重新登录或联系管理员 |
| 无管理权限 | 不显示管理入口，直接访问也返回无权限 |

邀请链接 72 小时失效；重置密码链接 30 分钟失效且只能使用一次。密码至少 12 位；正式账号密码必须由用户重新设置，Pages 临时密码和 ECS 企业凭证都不复用。

## 五、企业、用户与权限

正式账号至少保存下面这些业务信息；密码原文、激活链接和重置链接原文不得保存。

```json
{
  "organization": {
    "id": "org_example",
    "name": "正博星元工程管理咨询有限公司",
    "status": "active"
  },
  "user": {
    "id": "usr_001",
    "organizationId": "org_example",
    "email": "user@company.com",
    "name": "张三",
    "role": "platform_admin | organization_admin | member",
    "status": "invited | active | disabled",
    "lastLoginAt": "2026-08-21T09:30:00+08:00"
  }
}
```

| 角色 | 可看标讯 | 管理本企业成员 | 管理企业和全部用户 | 管理信息源 |
|---|---:|---:|---:|---:|
| 平台管理员 | 是 | 是 | 是 | 是 |
| 企业管理员 | 是 | 是 | 否 | 否 |
| 普通成员 | 是 | 否 | 否 | 否 |

在现有 `/radar/admin/` 中增加“企业与用户”入口，并按角色显示内容。平台管理员管理全部企业和用户；企业管理员只能邀请、停用本企业成员，不能修改企业归属或创建平台管理员。

## 六、三个阶段怎么切换？

```text
Pages 加密发布并完成浏览器验收
        ↓
线下发送临时共享密码
        ↓
ICP 通过、HTTPS 和备案信息就绪
        ↓
ECS 访问控制上线 → Pages 停止业务发布
        ↓
给每家企业发放独立 ECS 凭证
        ↓
独立账号系统上线 → 撤销全部临时凭证
```

切换日不要求用户同时通过两套密码。ECS 验收完成后，Pages 只保留迁移提示或停止发布业务数据；独立账号验证完成后，普通用户只看到正式登录页，Pages 密码和 ECS 企业凭证全部撤销。

## 七、职责

| 负责人 | 要完成的事 |
|---|---|
| 产品 | 线下分发临时密码；提供企业名称、企业管理员姓名和邮箱；确认停用名单 |
| 开发 | 完成 Pages 加密、ECS 访问规则、账号状态、权限判断和迁移 |
| 运维 | 管理 GitHub Secret、公司公网 IP、HTTPS、凭证文件、日志和旧入口状态 |
| 企业管理员 | 邀请本企业成员，及时停用离职或不再参与试用的人员 |

## 八、交付数量

临时阶段：1 个解锁页、1 份加密标讯快照、1 个 GitHub Secret、1 份 30 天本地凭证。

正式入口阶段：1 套 IP 白名单、每家企业 1 个独立凭证、1 套全站访问规则、1 组认证失败日志。

长期阶段：4 个用户入口页（登录、激活、忘记密码、重置密码）、3 种角色、3 种账号状态、1 个“企业与用户”管理入口。

**Pages 临时密码、ECS 企业凭证和个人账号不能混算或复用。** 前两种允许多人共用，长期阶段必须一人一号。

## 九、验收

### 临时阶段验收

1. 首次打开 GitHub Pages 的 `/radar/` 只显示解锁页，不显示项目内容；
2. 错误密码不能进入，正确密码能解密并显示当前标讯；
3. 同一浏览器 30 天内再次访问自动进入，新设备和无痕窗口重新要求密码；
4. 直接访问发布数据只能获得密文，构建产物中不存在明文 `radar.json`；
5. 仓库、构建日志和发布产物中均搜索不到临时密码；
6. 修改 GitHub Secret 并重新发布后，旧本地凭证不能解密新数据；
7. 手机和电脑的解锁、错误提示和自动进入行为一致。

### 正式入口阶段验收

1. 公司固定公网 IP 访问 `/`、`/radar/`、项目详情和管理页时不弹密码框；
2. 手机流量访问同一地址时必须出现认证框，正确企业凭证可以进入；
3. 错误密码、已撤销凭证均返回拒绝访问，连续失败受到限速；
4. 未认证时直接访问 `/data/radar.json`、JS、图片或深层路由都不能获取内容；
5. HTTP 只跳转 HTTPS，不通过明文连接接收密码；
6. 三家企业凭证可单独创建、轮换和撤销，互不影响；
7. GitHub Pages、服务器 IP、旧域名和其他部署地址不能绕过认证；
8. 公司公网 IP 改变后只转为要求密码，不会误放行新的未知 IP。

### 长期阶段验收

1. 平台管理员能创建企业并邀请企业管理员，邀请 72 小时后失效；
2. 受邀用户能设置自己的密码并登录，Pages 临时密码和 ECS 企业凭证不能登录个人账号；
3. 未登录用户访问任意业务深层链接时先登录，成功后返回原链接；
4. 企业管理员只能查看和管理本企业成员；普通成员看不到管理入口；
5. 账号停用后已有会话立即失效，再次访问不能读取页面或数据；
6. 连续输错 5 次后暂停登录 15 分钟，错误提示不暴露邮箱是否存在；
7. 重置链接 30 分钟失效且只能使用一次，重置后旧会话全部失效；
8. 登录、失败、退出、邀请、停用和密码重置都有时间、账号和结果记录；
9. 正式切换后普通用户只经过账号登录，不再出现浏览器原生认证框；
10. 三家意向企业各完成至少一名真实用户的邀请、激活、登录和停用演练后，才允许正式上线。
