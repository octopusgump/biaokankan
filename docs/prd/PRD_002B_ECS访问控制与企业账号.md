# PRD_002B｜ECS 访问控制与企业账号

> 状态：ICP 通过后执行；Pages 密码不能迁移为正式凭证｜2026-08-21

## 一、这是什么？

ICP 通过后，把业务入口从 Pages 切到 ECS。先用公司 IP 和企业凭证控制访问，再升级为一人一号。

| | ECS 企业凭证 | 企业个人账号 |
|---|---|---|
| 识别对象 | 公司网络或企业 | 具体用户 |
| 公司网络 | 固定公网 IP 免密 | 仍需个人登录 |
| 外部网络 | 每家企业一组凭证 | 每人自己的邮箱和密码 |
| 结束条件 | 个人账号上线后撤销 | 长期保留 |

**企业凭证不能当成个人账号。** 多人共用凭证的日志不能证明具体是哪位员工操作。

## 二、项目边界

**本项目只处理 ICP 后的访问入口和身份。** 第一阶段保护 ECS 全站，第二阶段提供邀请制个人账号。

不开放公众注册，不做微信、短信、SSO、多因素认证、套餐、支付、合同、发票、企业专属标讯、项目分派、收藏或跟进记录。新增企业业务数据时另写隔离方案。

Pages 加密继续以 [PRD_002A](./PRD_002A_GitHub_Pages临时加密试用.md) 为准。ICP 和 ECS 验收完成前，不向企业开放域名或公网 IP。

## 三、入口长这样

### ECS 企业凭证

公司登记网络直接进入；其他网络使用浏览器认证框：

```text
标看看封闭试用
用户名：[____________]
密码：  [____________]
[登录]
```

每家企业一组凭证，某家退出时只撤销该家。

### 企业个人账号

```text
登录标看看
企业邮箱：[name@company.com]
密码：    [________________]
[登录]  忘记密码
```

邀请链接 72 小时有效；重置链接 30 分钟有效且只能使用一次。

## 四、访问规则

| 情形 | 结果 |
|---|---|
| 公司已登记公网 IP | ECS 第一阶段免密进入 |
| 公司 IP 改变 | 要求企业凭证，不扩大白名单 |
| 企业凭证正确 / 已撤销 | 进入 / 拒绝访问 |
| 未登录个人访问业务页 | 登录后回到原地址 |
| 邀请未激活 | 只能设置密码 |
| 账号被停用 | 会话立即失效 |
| 连续输错 5 次 | 暂停该账号 15 分钟 |
| 会话超过 7 天 | 重新登录 |

HTML、脚本、图片、数据文件和深层路由使用同一规则。只保护首页不算完成；HTTP 只跳转 HTTPS，不接收密码。

## 五、企业与权限

| 角色 | 看标讯 | 管本企业成员 | 管全部企业 | 管信息源 |
|---|---:|---:|---:|---:|
| 平台管理员 | 是 | 是 | 是 | 是 |
| 企业管理员 | 是 | 是 | 否 | 否 |
| 普通成员 | 是 | 否 | 否 | 否 |

企业状态为有效或停用；用户状态为邀请中、有效或停用。企业凭证和正式密码至少 12 位，只保存哈希；密码、邀请链接和重置链接原文不能保存。正式账号必须重新设置密码，不能复用 Pages 密码或企业凭证。

## 六、切换顺序

```text
ICP、HTTPS、备案信息就绪
→ ECS 全站规则验收
→ 停止 Pages 业务数据发布
→ 给三家企业分别发凭证
→ 个人账号完成真实用户演练
→ 撤销全部企业共享凭证
```

用户在切换日不需要同时通过两套密码。

## 七、交付数量

```text
全站规则 1 套｜IP 白名单 1 套｜每家企业凭证 1 组
账号入口页 4 个｜角色 3 种｜账号状态 3 种｜企业与用户管理入口 1 个
```

企业凭证允许多人共用；个人账号必须一人一号，两者不能混算。

## 八、职责

| 负责人 | 要完成的事 |
|---|---|
| 产品 | 提供企业、管理员和停用名单 |
| 开发 | 实现全站规则、账号、权限和切换 |
| 运维 | 管理 IP、HTTPS、凭证、日志和旧入口 |
| 企业管理员 | 邀请和停用本企业成员 |

## 九、验收

### ECS 企业凭证

1. 公司固定 IP 访问四类入口免密，手机流量要求认证；
2. 三家凭证可分别创建、轮换和撤销；
3. 未认证时不能读取页面、静态资源、数据或深层路由；
4. 连续失败受到限速并写入日志；Pages、服务器 IP 和旧域名不能绕过。

### 企业个人账号

1. 平台管理员能创建企业并邀请企业管理员；
2. 企业管理员只能管理本企业成员，普通成员看不到管理入口；
3. 邀请和重置链接按规定失效，重置链接只能使用一次；
4. 账号停用后会话立即失效，连续输错 5 次后暂停 15 分钟；
5. 三家企业各完成至少一名用户的邀请、激活、登录和停用演练；
6. 正式切换后不再显示 Pages 解锁页或企业共享认证框。
