# PRD 目录

每个小功能单独创建一份 PRD，不把多个功能继续堆进产品总览。

## 文件命名

```text
PRD_三位序号_功能名称.md
```

例如：

```text
PRD_001_监理招标信息雷达_首版.md
PRD_002_企业微信每日汇总.md
PRD_003_项目地区筛选.md
```

规则：

1. 序号连续递增，已经使用的序号不重复；
2. 一个文件只写一个可以独立开发和验收的功能；
3. 同一功能的小修改直接更新原文件，新功能再创建新文件；
4. 已上线或取消的 PRD 保留，不删除，在下方索引标明状态；
5. 新建、改名或改变状态后，同步更新本页索引。
